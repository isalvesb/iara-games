# 🎮 Iara Games

## 🗒️ Descrição
O **Iara Games** é uma plataforma de jogos brasileira pensada para apoiar e destacar o talento das **pequenas desenvolvedoras nacionais**. Aqui, apenas jogos criados por empresas brasileiras têm espaço, reforçando uma identidade cultural própria e fortalecendo a comunidade de criadores locais.

---

## 📝 Sobre o Projeto
A **Iara Games** nasce com uma visão simples e poderosa: **valorizar e impulsionar os criadores de jogos do Brasil**. O nome escolhido foi para refletir essa essência - "Iara", figura marcante do folclore brasileiro, simboliza não só nossa cultura, mas também o encanto e o potencial criativo presente no território nacional; (e claro na criadora da ideia, a Iara).

A plataforma tem como princípio **dar destaque exclusivo às pequenas desenvolvedoras brasileiras**, criando um ambiente onde jogos nacionais possam brilhar sem competir com grandes empresas internacionais. Com isso, a Iara Games constrói uma **identidade única**, autenticamente brasileira, repleta de referências, inspirações e "brasilidades".
Essa proposta não é apenas um conceito visual, mas um propósito:

🌿 **promover talentos emergentes**,  
🎮 **fortalecer o ecossistema nacional de games**,  
🇧🇷 **celebrar a criatividade brasileira**.

---

## 🎯 Propósito da Plataforma
A Iara Games foi idealizada para ser um **ecossistema completo** que reúne jogadores, criadores e pequenas empresas nacionais. A plataforma permitirá **compra, venda e interação** totalmente indicadas às produções brasileiras, fortalecendo a cena independente e criando oportunidades reais para novos estúdios.

Além disso, associar a marca à identidade folclórica Iara oferece uma base forte para a criação de uma identidade visual futura: algo moderno, imersivo e cheio de referências culturais brasileiras - exatamente o tipo de personalidade que diferencia a plataforma no mercado.

---

## 🧪 Versão Piloto - Funcionalidades 
A versão inicial do Iara Games deverá incluir:

### 👤 Área do Usuário  
- Criar conta / Login
- Privacidade e segurança da conta
- Histórico de contas
- Encerrar sessão

### 🏪 Loja  
- Jogos ordenados por: **alfabética**, **mais comprados**, **melhor avaliação**, **categorias/gêneros**.

### 🎮 Biblioteca ("Jogos do Usuário")  
- Jogados / Comprados ordenados por data, nome, nota do usuário

### 🗨️ Fórum  
- Tópicos por: **data**, **mais comentados** e **priorizando os do usuário logado**.

### 🛠️ Suporte  
- Contatos de suporte
- Histórico de tickets do usuário
- Plataforma para abrir e acompanhar chamados

## ⚙️ Como Rodar Localmente
1. Clone o repositório
```bash
git clone https://guicunhasou.github.io/iara-games/
```
2. Abra ```index.html``` no navegador ou use um servidor local:
* Com Python:
  ```bash
  cd iara-games
  python -m http.server 8000
  ```

* Com VSCode:
  * Instale a extensão Live Server
  * Clique em "Go Live"
